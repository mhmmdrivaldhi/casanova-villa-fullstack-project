# Casanova Villa — Fullstack Development Project

Casanova Villa is a modern fullstack villa booking website built using Next.js, React.js, TypeScript, and PostgreSQL. This project focuses on creating a luxury villa reservation platform with authentication, room management, online booking, payment integration, and an admin dashboard.

---

## 🚀 Tech Stack

- Next.js
- React.js
- TypeScript
- PostgreSQL
- Tailwind CSS
- Prisma ORM
- NextAuth Authentication (Auth.js)
- Payment Gateway Integration
